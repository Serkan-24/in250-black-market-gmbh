# Security Policy

## Sicherheitsprobleme melden

Bitte melde Sicherheitslücken **nicht öffentlich über GitHub Issues**.

Nutze stattdessen:

- GitHub Security Advisory (falls aktiviert)
- oder E-Mail an den Repository-Maintainer

Bitte gib wenn möglich folgende Informationen an:

- betroffene Datei oder Komponente
- kurze Beschreibung der Schwachstelle
- Schritte zur Reproduktion
- mögliche Auswirkungen

## Unterstützte Versionen

| Version | Unterstützt |
|---------|-------------|
| main | ✅ |
| ältere Versionen | ❌ |

## Reaktionszeit

- Bestätigung der Meldung innerhalb von **3 Werktagen**
- Erste Einschätzung innerhalb von **7 Werktagen**
